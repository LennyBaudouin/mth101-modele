# Commandes client

Une commande client courte par fichier : `commande-01.md`, `commande-02.md`,
etc. Chaque réponse garde le même plan : les calculs, puis la recommandation
au client, en trois lignes, dans ses mots à lui.

Une commande se rend par un commit poussé avant l'échéance annoncée : la date
du commit fait foi.
