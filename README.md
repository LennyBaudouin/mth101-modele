# Dépôt de binôme · MTH101

Ce dépôt est celui de votre binôme pour le module MTH101, Probabilités,
distributions et aide à la décision. Tout votre travail y vit : notes de
séance, exercices, commandes client, projet. Son historique montre ce que
chacun a fait, et quand.

**Pour commencer : ouvrez [`PREMIERE-MISSION.md`](PREMIERE-MISSION.md).**

## Travailler sans rien installer

Le dépôt s'ouvre dans votre navigateur avec GitHub Codespaces : bouton vert
**Code**, onglet **Codespaces**, **Create codespace on main**. Le premier
démarrage prend quelques minutes, le temps d'installer Python, pandas, NumPy,
SciPy, matplotlib et Jupyter. Si VS Code demande s'il peut faire confiance
aux auteurs du dossier, acceptez : c'est votre dépôt. Pour vérifier
l'environnement, ouvrez `exercices/00-verifier-environnement.ipynb` et
lancez-le (**Exécuter tout**, *Run All*).

Codespaces est gratuit dans la limite d'un quota mensuel, d'environ
60 heures d'utilisation. Un codespace s'arrête seul après 30 minutes
d'inactivité ; en fin de séance, arrêtez-le vous-même. Ce qui n'a pas été
commité et poussé n'existe que dans ce codespace.

## L'arborescence

| Dossier | Contenu |
|---|---|
| `notes/` | Une note par séance |
| `exercices/` | Vos réponses aux exercices des fascicules |
| `commandes/` | Les commandes client courtes, une par fichier |
| `projet/protocole/` | Le protocole de votre mission, commité avant toute analyse |
| `projet/donnees/` | Les données de la mission et leur provenance |
| `projet/analyses/` | Les notebooks d'analyse |
| `projet/simulateur/` | Le simulateur de votre modèle de décision |
| `projet/soutenance/` | Le support et la fiche de soutenance |

Chaque dossier contient un `README.md` qui dit ce qu'on y range.

## Les règles de l'agence

- **Commitez souvent**, avec un message qui dit ce que vous avez fait.
- **Chacun commite depuis son propre compte.** L'historique rend lisible la
  contribution de chaque membre du binôme.
- **Aucune donnée personnelle** d'une autre personne : ni nom, ni adresse, ni
  téléphone, ni photo. Les questionnaires sont anonymes.
- **Aucun secret** : jamais de mot de passe ni de clé d'API dans un fichier
  du dépôt, même privé.
- **Toute donnée a une source** : citez-la, avec sa licence, dans le
  `README.md` du dossier qui la contient.
- Le dépôt reste **privé**. Seuls les deux membres du binôme et
  l'intervenant (`Ad-C`) y ont accès.
