# Projet

Le dossier de votre mission. Les missions sont présentées le vendredi
9 octobre ; chaque sous-dossier se remplit au fil du projet.

| Dossier | Contenu |
|---|---|
| `protocole/` | Le protocole de la mission, commité avant toute analyse |
| `donnees/` | Les données et leur provenance |
| `analyses/` | Les notebooks d'analyse |
| `simulateur/` | Le simulateur du modèle de décision |
| `soutenance/` | Le support et la fiche de soutenance |
